# Specification-driven development

Create, refine, review, or track a specification and its implementation when requirements, acceptance criteria, and traceability need to be explicit; also serve an SDD Builder request queue when explicitly requested.

## Usage

Read [SKILL.md](SKILL.md) for the workflow and its constraints.

Scale specifications to the task; a request for a specification does not itself authorize implementation.
